## 🧠 What's My Purpose?

This repository hosts a txt file that is the initial seed of the Cleaning Schedule database read by [Home Page Api](https://github.com/rbrock44/home-page-api). 
Another application [cleaning-schedule-backup-sync](https://github.com/rbrock44/cleaning-schedule-backup-sync) was built (and ran on a scehdule) to keep this repo up do date with the [Home Page Api LIVE database](https://home-page-api.ryan-brock.com/cleaning-schedule)
